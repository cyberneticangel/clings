#define MIN(a, b) ((a) < (b) ? (a) : (b))
CLAMP can reuse them: MIN(MAX((x), (lo)), (hi))
SWAP: do { type tmp_ = (a); (a) = (b); (b) = tmp_; } while (0)
(Without do/while(0), the `if (...) SWAP(...); else` breaks: the `;` after
a { } block ends the if, leaving a dangling else.)
EXPECT_EQ: do { if ((a) != (b)) record_failure(#a " == " #b, __LINE__); } while (0)
